송월교회 출석앱 — 실시간 연동 설정

Firebase config를 입력하면 완성된 앱 파일을 즉시 다운로드합니다

아래 4단계를 따라하면 됩니다. 전부 무료이고 약 10분 걸립니다.
1

Firebase 프로젝트 만들기

  1. console.firebase.google.com 접속 (구글 계정 로그인)
  2. 프로젝트 추가 → 이름: songwol-attendance
  3. Google 애널리틱스 사용 안 함 → 프로젝트 만들기
2

Firestore 데이터베이스 만들기

  1. 왼쪽 메뉴 Firestore Database → 데이터베이스 만들기
  2. 위치: asia-northeast3 (서울)
  3. 테스트 모드로 시작 → 만들기
  4. 규칙 탭 → 아래로 교체 후 게시: 
    rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /songwolAttendance/{docId} {
      allow read: if true;
      allow write: if request.auth != null;
    }
    match /songwolMeta/{docId} {
      allow read: if true;
      allow write: if request.auth != null;
    }
    match /songwolPhotos/{docId} {
      allow read: if true;
      allow write: if request.auth != null;
    }
  }
}
3

익명 인증 활성화

  1. 왼쪽 메뉴 Authentication → 시작하기
  2. 로그인 방법 탭 → 익명 클릭
  3. 사용 설정 켜기 → 저장
4

앱 등록 및 Config 복사

  1. 상단 ⚙️ 프로젝트 설정 → 내 앱 → </> (웹) 클릭
  2. 앱 닉네임 입력 → 앱 등록
  3. firebaseConfig 값 확인
5

다운로드한 파일을 GitHub에 올리기

  1. github.com/L2L2L2L2/study → songwol/index.html 접속
  2. 우측 상단 ✏️ 편집(연필) 아이콘 클릭
  3. 전체 선택(Ctrl+A) 후 다운로드된 파일 내용 전체 붙여넣기
  4. 하단 Commit changes 클릭 → 약 30초 후 자동 반영
💡 파일이 330KB라서 붙여넣기 시 잠깐 멈출 수 있어요. 기다려주세요.

Firebase Config 입력

Firebase 콘솔 → 프로젝트 설정 → 내 앱 → firebaseConfig 에서 복사해서 붙여넣으세요

전체 config 코드 붙여넣기 (자동 파싱)
또는 항목별 직접 입력
6개 항목 모두 입력됨 — 다운로드 가능합니다
다운로드 후 GitHub에 올리기
① 이 링크에서 ✏️ 편집 아이콘 클릭
② 전체 선택(Ctrl+A) 후 다운로드된 파일 내용 전체 붙여넣기
③ Commit changes 클릭 → 30초 후 자동 반영
