# 🚅 도시철도 열차 운전실 모바일 훈련 시뮬레이터 (Train Cockpit Simulator)

[![Live Demo](https://img.shields.io/badge/Live_Demo-GitHub_Pages-2ea44f?style=for-the-badge&logo=github)](https://l2l2l2l2.github.io/study/)
[![Tech](https://img.shields.io/badge/Tech-HTML5_·_Canvas2D_·_Web_Audio_API-orange?style=for-the-badge)](https://l2l2l2l2.github.io/study/)
[![License](https://img.shields.io/badge/License-MIT-blue?style=for-the-badge)](LICENSE)

실제 도시철도 전동차 운전실 조작반(OP1~OP5)과 전면 창밖 선로 뷰를 실물 사진 기반으로 정밀 고증하고, 완전한 전기·공압 인터록(Interlock) 논리와 3D 의사(Pseudo-3D) 주행 시뮬레이션을 구현한 **단일 파일(`index.html`) 완성형 웹 애플리케이션**입니다.

별도의 외부 프레임워크, 3D 엔진(Unity/Three.js), 사운드 파일 다운로드 없이 **표준 웹 기술(HTML5, Canvas, Web Audio API, SVG)**만으로 가볍고 빠르게 동작합니다.

## 📸 조작반 구성 (OP1 ~ OP5)

```
┌─────────────────────────── [ 운전실 패널 배치 ] ───────────────────────────┐
│ [OP1] 운전실 주 제어반     │ [OP2] 상부 제어반   │ [OP3] A필러 비상제동반   │
│ - 3D 전면 주행 뷰 모니터   │ - 운전모드 4단       │ - 비상제동체결 (E-Stop)   │
│ - 통화/방송 마이크 & COB   │ - 제어키 (Master Key)│ - 비상제동완해 (커버/버튼) │
│ - 출입문 개폐 스위치       │ - 전면창 히터 (2단)   │ - 무인모드 (3초 롱프레스) │
│ - T-bar 마스콘 (EB~P4)     │ - 선두차지정 표시등   │ - 강제완해, 주차제동체결/완해│
│ - 전후진제어기 볼 노브(F/N/R)│                    │ - ATP후진, 저속도, 실내등, 구원│
├───────────────────────────┴─────────────────────┼─────────────────────────┤
│ [OP4] 메인 계기 및 바이패스                     │ [OP5] 보조 조작반       │
│ - MR / BC 듀얼 공기 압력계 (실시간 연동)         │ - VOBC 리셋 (롱프레스)  │
│ - 와이퍼 (OFF/INT/LOW/HIGH), 출입문 히터         │ - 언커플링, 고속도차단기│
│ - 장애물 감지 바이패스, 공기질 개선 스위치       │ - 주공기BP, PWM차단 등  │
└─────────────────────────────────────────────────┴─────────────────────────┘
```

## 🚀 주요 핵심 기능 및 시스템 아키텍처

### 1. 3D 의사(Pseudo-3D) 전면 주행 뷰 시뮬레이터
- **실물 사진 창틀 마스킹 (`cvWindowPath`)**: 운전실 전면 실물 사진(`cab_view.png`)에서 유리창 개구부를 정밀하게 도려내어, 운전실 프레임 너머로 선로가 보이도록 전경/배경 렌더링을 합성했습니다.
- **선로 궤도 렌더링**: 1,435mm 표준 궤간 레일, 침목(0.62m 간격 위상 동기화), 도상 자갈, 전차선 가선주(Catenary), 선로변 방음벽, 울타리, 수목 및 도심 건물 3D 원근 투영.
- **인천 2호선 역 승강장 연동**: `검단오류` ➔ `왕길` ➔ `검단사거리` ➔ `마전` ➔ `완정` ➔ `독정` ➔ `검암` ➔ `주안국가산단` 승강장 진입 및 통과.
- **환경 및 기상 변화**:
  - **터널 구간**: 터널 진입 시 자연스러운 암전, 입체 아치형 조명 및 벽면 반사광 연동.
  - **우천 및 와이퍼**: 주행 구간에 따른 강우 시각화, 앞유리 물방울 물리 효과 및 와이퍼 작동(`cvUpdateWiper`) 시 유리 표면 빗방울 닦임 효과.
- **실감 음향 연동**: 속도에 따른 인버터 모터 구동음, 레일 차륜 롤링 소음, 25m 주기 레일 이음매 충격음(`Joint Clack`) 실시간 합성.

### 2. 엄격한 철도 운전 규정 인터록(Interlock) 논리
- **운전모드 `OFF` 상태 인터록 (운전대 완전 잠금)**:
  - 운전모드가 `OFF`일 때는 제어키(Master Key)를 `ON`으로 돌릴 수 없으며, 전후진제어기(F/R) 및 마스콘(P단/B단) 조작이 기계적으로 차단됩니다.
  - `OFF`로 전환 시 기존 투입되어 있던 키와 레버들이 안전하게 `OFF` 및 `N`(중립)으로 자동 복귀합니다.
- **무인운전모드(ATO) 4대 조건 검증 & 3초 롱프레스 자동 주행**:
  - `운전모드 OFF` + `제어키 OFF` + `전후진제어기 N` + `마스콘 핸들 N`의 4대 조건을 모두 만족하고 투명 보호커버가 열린 상태에서 무인운전 버튼을 3초 이상 길게 누르면 녹색 점등(`LIT`)되며 ATO 무인운전이 가동됩니다.
  - 열차가 60 km/h 목표 속도로 자동 가속 및 순항 주행하며, OSD에 `ATO 무인` 노치 태그와 `무인운전 (ATO)` 배지가 표시됩니다.
- **수동 운전 모드 (`FM`, `RM`, `ATPM`)**:
  - 운전모드가 `FM`(완전 수동), `RM`(제한 수동), `ATPM`(신호 수동) 중 하나여야만 제어키 `ON` 및 레버 조작이 가능합니다.
  - **RM 모드 최고속도 25 km/h 자동 제한**: 가속 노치를 P4로 올려도 25 km/h를 초과하지 않습니다.
  - 수동 모드로 전환 시 진행 중이던 무인운전은 안전하게 자동 해제됩니다.
- **선두차지정 표시등 점등**: `운전모드(FM/RM/ATPM) + 제어키(ON) + 전후진제어기(F/R)` 3중 조건 만족 시에만 OP2 황색 인디케이터가 점등합니다.
- **제동통(BC) 공압 연동**:
  - 상용제동: B1(2.3 bar) ~ B7(4.0 bar), 타행(N) 0.0 bar.
  - 비상제동(EB 노치 또는 OP3 E-Stop 버튼): 즉시 4.0 bar 급상승 및 [제동체결] 적색등 점등.
  - 비상제동완해: 커버 오픈 후 버튼 조작 시 0.0 bar 배기 및 [비상제동차단] 적색등 점등.

### 3. 물리 가속 및 속도 폭주 방지 엔진
- **내리막 구배 가속 상한선 보장**: 내리막 구배(`gradeAcc`) 가속 상황에서도 `Math.min(target, ...)` 캡핑을 통해 현재 목표 속도(`target`)를 절대 초과하지 않습니다.
- **모드 전환(FM ➔ RM) 안전 감속력 보장**: 고속(60~80 km/h) 주행 중 RM(25 km/h)으로 전환하거나 노치를 낮출 때, `decel = Math.min(rate, -2.5)`로 확실한 감속을 강제합니다.
- **절대 상한선 이중 안전 캡핑**: RM 모드는 25.0 km/h, FM/ATPM 모드는 80.0 km/h를 초과할 수 없도록 이중 안전장치를 내장했습니다.

### 4. 100% Web Audio API 기반 기계 음향 합성
- **통신 및 사운드**:
  - 방송 마이크 PTT 터치 시 실제 무전기 잡음인 **"치지직" 라디오 노이즈** 합성 출력.
  - COB 통신 버튼(비상응답, 운전실통화, 실내방송, 실외방송) 누름 시 **전자 비프음(Beep)** 연동.
- **공압 및 기계음**:
  - 주차제동 체결/완해 시 1.0초간 공압이 뿜어져 나오는 **"치이이이익~~~~" 감압 배기음**.
  - 비상제동 버섯형 헤드 체결 시 묵직한 메탈릭 래치 체결음, 로터리 스위치 회전 시 찰칵 스냅음.
  - 전기혼 경적: 실제 전동차 F#4(370Hz) + A4(440Hz) 듀얼 톤 화음 기적음.
- **하이브리드 햅틱**: 모바일 기기 진동 모터(`navigator.vibrate`) 및 52Hz 서브베이스 오디오 햅틱 동시 지원.

### 5. 멀티 슬롯 반응형 뷰포트 (100dvh & 2분할/3분할)
- **스마트폰 세로 모드 (< 768px)**: 1열 슬롯 기반, 상단 탭을 통한 패널 즉시 전환.
- **태블릿 / 폴더블 (>= 768px)**: 2분할 듀얼 뷰포트 (좌·우 독립 패널 조작 & 스마트 스왑).
- **PC / 와이드 모니터**: **3분할 트리플 뷰포트** 지원으로 OP1(운전대/전면뷰), OP2~OP3(주요 조작반), OP4~OP5(보조 조작반)를 한 화면에서 넓게 감시하며 실습 가능.

### 6. 체계적인 4대 훈련 모드
1. **자유 테스트 모드 (FREE)**: 시나리오 구애 없이 모든 스위치와 인터록을 샌드박스로 자유 실습.
2. **실습 훈련 모드 (PLAY)**: 지시문 문구, 스마트 타겟 펄스(노란 점선 깜빡임), 자동 패널 전환, 힌트 가이드 제공.
3. **실전 평가 모드 (EXAM)**: 시각적 힌트 제거, 1초 단위 스톱워치, 오조작 감점 집계 및 성적 리포트(A+/A/B/RE-EXAM) 자동 발행.
4. **동작 녹화 모드 (REC)**: 교관이 직접 화면을 조작하여 코딩 없이 새로운 시나리오를 즉석 저작 및 JSON 내보내기/가져오기 지원.

## 💻 실행 방법

별도의 Node.js 서버나 빌드 과정 없이 `index.html` 파일을 더블 클릭하여 크롬, 엣지, 사파리 등의 웹 브라우저에서 열면 즉시 실행됩니다.

```bash
# 저장소 복제
git clone https://github.com/L2L2L2L2/study.git

# 폴더 이동 후 index.html 브라우저 실행
cd study
# Windows의 경우
start index.html
```
