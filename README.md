# 열차 운전실 좌측 패널 모바일 훈련 웹앱 (Train Cockpit Panel Simulator)

철도 기관사 및 승무원을 위한 열차 운전실 좌측 조작반(A필러 긴급/제동 패널 & 메인 바이패스 조작반) 모바일 훈련 시뮬레이터입니다.

외부 서버 및 라이브러리 없이 브라우저에서 즉시 실행 가능한 **단일 파일(`index.html`) 완성형 웹 애플리케이션**입니다.

---

## 📸 실제 운전실 조작반 기반 구현
실제 열차 운전실 좌측 조작반 사진을 분석하여 100% 실물 배치와 동작 사양을 정밀 구현했습니다.

- **A필러 긴급 제동 패널**:
  - `비상제동체결` (버섯형 래치 E-STOP 버튼)
  - `강제완해` (원형 푸시 버튼)
  - `비상제동완해` (투명 아크릴 안전 플립 커버 + 내부 푸시 버튼)
  - `ATP후진` (투명 커버 + 2단 로터리 스위치)
  - `저속도` (정상 ↔ 우회 2단 셀렉터)
  - `주차제동체결` / `주차제동완해` (1.0초 공압 배기음 연동 푸시 버튼)
  - `무선모드` (투명 커버 + 녹색 버튼)
  - `실내등` (수동 / 자동 / 비상등 3단 셀렉터)
  - `구원운전` (구원 / 정상 / 비상 3단 셀렉터)
- **메인 계기 & 바이패스 패널**:
  - `공기 압력계(MR, BC)`: 주공기통(MR 9.0 bar 고정), 제동통(BC 0~4.5 bar 실시간 물리 연동)
  - `출입문 바이패스` / `장애물 감지 바이패스`
  - `공기질개선장치 작동스위치` (AUTO / OFF / ON)
  - `와이퍼 제어 스위치` (OFF / INT / FAST)

## 🚀 주요 기능
1. **Web Audio API 기반 1.0초 공압 배기음 & 기계음 자체 합성**:
   - 주차제동 체결/완해, 비상제동 완해 시 열차 특유의 실감나는 **"치이이이익~~~~" 1.0초 배기음** 및 묵직한 릴레이 소리 재생.
2. **실무 훈련 시나리오 4종 기본 탑재**:
   - 비상제동 체결 및 완해 절차
   - 출입문 닫힘 불량 바이패스 및 구원운전
   - 주차제동 점검 및 체결 절차
   - ATP 차상장치 이상 후진 운전 절차
3. **노코드 동작 녹화 모드 (Authoring Tool)**:
   - 교관이 화면의 스위치를 조작하는 것만으로 자동으로 스텝이 기록되는 실시간 시나리오 저작 기능 탑재.
   - JSON 내보내기/가져오기를 통한 교육생 간 시나리오 공유 지원.
4. **실습 훈련 vs 실전 평가 모드**:
   - 힌트 가이드(노란색 점선 펄스) 지원.
   - 실전 평가 시 타이머, 오조작 감점 및 성적표(A+/A/B/RE-EXAM) 자동 산출.
