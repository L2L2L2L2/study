# 🚅 인천2호선 열차 운전실 훈련 시뮬레이터 (Train Cockpit Simulator)

[![Live Demo](https://img.shields.io/badge/Live_Demo-GitHub_Pages-2ea44f?style=for-the-badge&logo=github)](https://l2l2l2l2.github.io/study/)
[![Tech](https://img.shields.io/badge/Tech-Three.js_r160_·_Web_Audio_API-orange?style=for-the-badge)](https://l2l2l2l2.github.io/study/)

인천2호선 전동차 운전실 콘솔(OP1~OP5, DU, ADU, 차단기반)을 실물 배치대로 옮기고, 실제 노선 **201 검단오류 → 227 운연 (27개 역, 약 29.1 km)** 을 Three.js 3D 전면 전망으로 달리는 웹 훈련 시뮬레이터입니다.
전기·공압 인터록, 수동운전(FM/RM/ATPM)과 무인운전(ATO), 시나리오 실습·평가까지 브라우저 하나로 동작합니다.

- **바로 실행**: **[https://l2l2l2l2.github.io/study/](https://l2l2l2l2.github.io/study/)**
- 이전 버전(Canvas 2D 단일 파일)은 **[`/old/`](https://l2l2l2l2.github.io/study/old/)** 에 그대로 보관되어 있습니다.

## 🖥️ 화면 구성

```
┌──────────────────────── 3D 전면 전망 ────────────────────────┐┌──── 선택 패널 ────┐
│ ⚙️ 메뉴            [OSD: 전후진·노치 · 속도]                  ││ OP2 / OP3 / OP4 / │
│                                                              ││ OP5 / OCC 중 하나 │
│ [OP2] [OP3] [OP4] [OP5] [차단기] [OCC]  ← 하단 선택 버튼      ││                   │
├──────────────────────────────┬───────────────────────────────┤├───────────────────┤
│ DU (TCMS 운전일반)           │ ADU (속도계 · ATO/ATC)        ││ OP1 (상시 표시)   │
└──────────────────────────────┴───────────────────────────────┘└───────────────────┘
```

- 실물 콘솔처럼 **OP1은 항상 보이고**, 좌측 패널(OP2~OP5)은 3D 화면 하단 버튼으로 골라 봅니다.
- 상단 탭(OP1~OP5, DU, ADU)으로 패널 하나만 크게 볼 수도 있습니다.
- 스마트폰 세로(1분할), 태블릿·폴더블(2분할), PC·와이드 모니터(3분할)에 맞춰 배치가 바뀝니다. 상단 `2분할 / 3분할` 칩으로 직접 고를 수 있습니다.

## 🚀 주요 기능

### 1. 3D 전면 전망 (`js/cabview3d.js`)
- `route.js`의 실제 선형(곡선·구배·지상/지하·고가)을 따라 선로, 제3궤조, 침목, 건넘선, 위치 태그(25 m 간격), 터널(박스형·원형)과 갱구, 옹벽, 방음벽, 지상 건물·수목·가로등을 그립니다.
- 역마다 승강장, PSD, 역명판, 정차위치표지를 두고, 반대편 선로로 마주 오는 열차(기존차·신조차, 진행 방향에 맞는 행선 표시)가 지나갑니다.
- 전조등 조명, 지하 구간 조명, 비·전면창 빗방울과 와이퍼 효과를 표현합니다. 고가 승강장 지붕 아래에서는 비가 내리지 않습니다.
- 성능을 위해 열차 주변 약 1.3 km만 150 m 단위로 만들고 지웁니다. 메뉴의 **3D 화질**(자동/선명/보통/가볍게)로 해상도를 조절하며, 선택은 브라우저에 기억됩니다.

### 2. 운전 모드와 인터록
- **운전 모드 OFF**: 제어키를 ON으로 돌릴 수 없고 전후진제어기·마스콘 조작이 막힙니다. 무인운전이 아닌 상태에서 OFF면 비상제동과 정차제동이 걸립니다.
- **FM**: 제한속도 정보 없이 최대 80 km/h.
- **RM**: 허용속도 15 km/h. 15~17 km/h로 5초 넘게 달리거나 18 km/h 이상이면 비상제동이 걸립니다. 고속 주행 중 RM으로 바꿔도 같은 감시가 적용됩니다.
- **ATPM**: 노선 구간별 제한속도(45·60 구간, 그 외 80 km/h)를 따릅니다.
- 제동통(BC) 압력은 상용제동 B1~B7, 비상제동, 정차제동(2.0 bar)에 맞춰 압력계와 연동되고, 비상제동 체결/완해와 주차제동은 표시등과 함께 동작합니다.
- **VOBC 위치 상실**: 전·후부 VOBC 리셋 후에는 POSITION LOST 상태가 되어 자동 주행이 안 되고, RM으로 위치 태그 2개를 지나야 풀립니다.

### 3. 무인운전 (ATO)
- 조건: **운전모드 OFF + 제어키 OFF + 전후진제어기 N + 마스콘 N**. OP3 무인모드 보호커버를 열고 버튼을 **3초 이상** 누르면 점등되며 투입됩니다.
- 투입 후에는 역간 주행, TASC 포물선 감속, 정위치 정차(정차제동 2.0 bar), 출입문·PSD 열림(승하차 8초), 닫힘 경고음, 자동 출발까지 스스로 합니다.
- 수동 모드(FM/RM/ATPM)로 돌리면 무인운전은 해제됩니다.

### 4. 운행 설정 (⚙️ 메뉴)
- **출발역 선택**: 운행 방향(하선 201→227 / 상선 227→201)과 출발역을 골라 정차 위치에 배치합니다.
- **운행 방향 전환**, **기점역으로 회차**, **종착역으로 바로 이동**, **처음부터 재시작**.
- **전시 모드 (무한 왕복)**: 하선 검단오류 → 운연, 종착 후 8초 대기, 상선 운연 → 검단오류를 무인운전으로 끝없이 반복합니다. 화면 위 `전시 모드 종료` 버튼으로 멈추면 이번 종착역에서 운행을 마칩니다.

### 5. 훈련 모드
1. **자유 테스트 (FREE)**: 시나리오 없이 모든 스위치와 인터록을 자유롭게 실습합니다.
2. **실습 훈련 (PLAY)**: 지시문, 조작 대상 깜빡임 표시, 자동 패널 전환, 힌트를 제공합니다.
3. **실전 평가 (EXAM)**: 힌트 없이 시간 측정, 오조작 감점, 성적 리포트를 냅니다.
4. **동작 녹화 (REC)**: 교관이 직접 조작해 새 시나리오를 만들고 JSON으로 내보내기/가져오기 합니다.

### 6. 원격 교육과 종합관제실(OCC)
- 상단 `📡 원격교육` 버튼에서 Supabase URL·키와 방(room) 이름을 넣으면 교관과 훈련생 화면이 실시간으로 연결됩니다.
- **OCC 패널**에서 열차 속도·BC·표시등을 감시하고, VOBC 고장·통신고장 같은 장애를 주입할 수 있습니다.

### 7. 사운드와 햅틱 (Web Audio API)
- 음원 파일 없이 인버터 모터음, 레일 주행음, 공압 배기음, 스위치 소리, 전기혼, 방송 잡음, 출입문 경고음 등을 합성합니다.
- 모바일에서는 진동(`navigator.vibrate`)도 함께 씁니다. 상단 🔊 버튼으로 음소거합니다.

## 💻 실행 방법

메인 버전은 파일이 나뉘어 있고 ES 모듈을 쓰기 때문에 `index.html`을 더블 클릭해서는 열리지 않습니다. GitHub Pages 같은 웹 서버로 열어야 합니다.
Three.js와 Supabase SDK는 CDN에서 불러오므로 인터넷 연결이 필요합니다.

```bash
git clone https://github.com/L2L2L2L2/study.git
cd study
python -m http.server 8000
# 브라우저에서 http://localhost:8000/ 접속
```
