# 열차 운전실 좌측 패널 모바일 훈련 웹앱 (Train Cockpit Panel Simulator)

철도 기관사 및 승무원을 위한 열차 운전실 좌측 조작반 모바일 훈련 시뮬레이터입니다.

외부 서버 및 라이브러리 없이 브라우저에서 즉시 실행 가능한 **단일 파일(`index.html`) 완성형 웹 애플리케이션**입니다.

---

## 📸 실제 운전실 조작반 기반 구현 (OP1 ~ OP5)
실제 열차 운전실 좌측 조작반 사진을 분석하여 100% 실물 배치와 동작 사양을 정밀 구현했습니다.  
패널 상단의 불필요한 설명 태그를 전면 제거하여 실제 차량 조작반의 깔끔한 질감을 그대로 재현했습니다.

- **OP1 / OP2 (예비 조작반)**:
  - 향후 추가 스위치 및 제어 장비 배치를 위한 예비 패널 (스위치 대기)
- **OP3 (A필러 긴급 제동 패널)**:
  - `비상제동체결` (실물 동일 3-Arrow Turn to Reset 버섯형 래치 버튼)
  - `강제완해` (원형 푸시 버튼)
  - `비상제동완해` (투명 안전 아크릴 플립 커버 + 내부 적색 푸시 버튼)
  - `ATP후진` (투명 안전 아크릴 플립 커버 + 커버 밀착 OFF/ON 2단 로터리 스위치, 기계식 딱! 소리)
  - `저속도` (정상 ↔ 바이패스 2단 셀렉터, 기계식 딱! 소리 연동)
  - `주차제동체결` / `주차제동완해` (1.0초 공압 배기음 연동 푸시 버튼)
  - `무인모드` (투명 안전 아크릴 플립 커버 + 3초 롱프레스 인가 시 환하게 녹색 LED 점등)
  - `실내등` (수동 ↔ 자동 ↔ 비상등 왕복 이동 3단 셀렉터, 딱! 소리 연동)
  - `구원운전` (구원 ↔ 정상 ↔ 비상 왕복 이동 3단 셀렉터, 딱! 소리 연동)
- **OP4 (메인 계기 & 바이패스 조작반, 실물 3열 그리드)**:
  - **1행**: `예비(로터리)` | `와이퍼(실물 5단계 사각 셀렉터: AUTO / OFF / INT / SLOW / FAST 각 위치별 직접 터치 및 순환 회전, 레버형 노브)` | `예비(원형 녹색 푸시버튼)`
  - **2행**: `장애물 감지(정상/바이패스 로터리)` | `출입문(정상/바이패스 로터리)` | `출입문 히터(누름 시 쑥 들어간 채 유지되고 재터치 시 복귀하는 래치 푸시버튼)`
  - **3행**: `공기 압력계(MR/BC)` (실물 검은 사각 볼트 베젤 게이지, 2열 차지, MR 9.0 bar / BC 실시간 물리 연동) | `공기질개선장치 작동스위치` (실물 사각 알루미늄 명판 AUTO(미세먼지)/OFF/ON, 1열 차지)
- **OP5 (보조 조작반, 실물 사진 100% 동일 2행 4열)**:
  - **1행**: `VOBC리셋` (원형 녹색 푸시버튼: 2~3초 누름 시 "해당차 재설정", 5~7초 누름 시 "전·후부 VOBC 모두 리셋", 패널 하단 오버레이 가이드 및 실시간 미터·중앙 팝업 메시지 연동) | `언커플링` (적색 래치 조명 버튼: 누르면 쑥 들어가며 점등 유지, 재터치 시 복귀 및 소등) | `고속도차단기동작` (적색 래치 조명 버튼) | `주공기BP` (정상/바이패스 2단 로터리)
  - **2행**: `PWM차단` (적색 래치 조명 버튼: 누르면 쑥 들어가며 점등 유지) | `살사시험` (적색 푸시) | `절연구간` (정상/절연구간 2단 로터리) | `주차제동BP` (정상/바이패스 2단 로터리)

## 🚀 주요 기능
1. **Web Audio API 기반 1.0초 공압 배기음 & 기계음 자체 합성**:
   - 주차제동 체결/완해 시에만 열차 특유의 실감나는 **"치이이이익~~~~" 1.0초 배기음** 재생 (그 외 푸시버튼은 딸깍음).
   - ATP후진, 저속도, 실내등, 구원운전 등 로터리 스위치 회전 시 묵직한 기계식 **"딱!"(Rotary Snap)** 찰칵음 연동.
   - iOS(아이폰) 및 안드로이드 하이브리드 햅틱 (Apple Web 표준 한계를 보완하는 52Hz 서브베이스 오디오 햅틱 탑재).
2. **실내등 / 구원운전 3단 스위치 왕복 이동(바운스)**:
   - 오른쪽 끝(비상)까지 도달 후 다시 조작 시 왼쪽 끝으로 차례대로 왕복 회전.
3. **실무 훈련 시나리오 4종 기본 탑재**:
   - 비상제동 체결 및 완해 절차
   - 출입문 닫힘 불량 바이패스 및 구원운전
   - 주차제동 점검 및 체결 절차
   - ATP 차상장치 이상 후진 운전 절차
4. **노코드 동작 녹화 모드 (Authoring Tool)**:
   - 교관이 화면의 스위치를 조작하는 것만으로 자동으로 스텝이 기록되는 실시간 시나리오 저작 기능 탑재.
   - JSON 내보내기/가져오기를 통한 교육생 간 시나리오 공유 지원.
5. **실습 훈련 vs 실전 평가 모드**:
   - 힌트 가이드(노란색 점선 펄스) 지원.
   - 실전 평가 시 타이머, 오조작 감점 및 성적표(A+/A/B/RE-EXAM) 자동 산출.
