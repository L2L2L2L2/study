# ⚡ 4. 웹 기술 및 아키텍처 (Technical Implementation)

메인 버전은 3D 전면 전망에만 **Three.js r160**을 쓰고, 조작반·DU·ADU·물리·사운드는 표준 웹 기술(HTML5, CSS3, JavaScript, SVG, Canvas 2D, Web Audio API)로 구현했습니다. 이전 Canvas 2D 의사 3D 버전은 `old/index.html`에 보관되어 있습니다.

---

## 0. 파일 구성

| 파일 | 내용 |
| :--- | :--- |
| `index.html` | 조작반(OP1~OP5), DU, ADU, 차단기반, 열차 동역학, 무인운전, 시나리오, 사운드 |
| `js/route.js` | 인천 2호선 노선 데이터 (`window.IC2`): 역간 거리, 곡선·설계속도, 구배, 건넘선, 지상/고가/지하 구간. 3D 전망과 운전 로직이 함께 쓰는 단일 기준 |
| `js/cabview3d.js` | 3D 전면 전망 ES 모듈 (`window.CabView3D`) |
| `route-view.html` | 노선 평면도, 종단면(구배), 설계속도를 `js/route.js`에서 그려 확인하는 페이지 |
| `view-demo.html` | 3D 전면 전망 단독 시험 페이지 |
| `old/index.html` | 이전 버전 (단일 파일) |

* Three.js는 `importmap`으로 jsDelivr CDN(`three@0.160.0`)에서 불러옵니다. 파일이 나뉘어 있어 GitHub Pages 같은 웹 서버로 열어야 합니다 (로컬: `python -m http.server`).
* `js/route.js`와 `js/cabview3d.js`는 `?v=` 버전 쿼리를 붙여 불러오므로, 새 빌드를 올리면 브라우저 캐시 대신 새 파일을 받습니다.

## 1. 3D 전면 전망 엔진 (`js/cabview3d.js`)

### ① 운전 로직과의 연결
* 매 프레임 `CabView3D.update({ dir, s, v, rain, wiper, headlight, doorsOpen })`를 호출합니다. 운전 로직은 진행방향 거리를 `IC2.P.toS()`로 실제 위치 `s`로 바꿔 전달합니다.
* 하선(`dir = +1`, s 증가)과 상선(`dir = -1`, s 감소) 모두 카메라, 청크 생성, 반대편 열차, 정지위치 표지가 방향을 따릅니다.

### ② 청크 스트리밍
* 열차 앞 1,050 m · 뒤 300 m 범위만 150 m 청크 단위로 생성·해제합니다. 그림자를 쓰지 않고 지하 조명은 정점 색에 미리 구워 내장 그래픽에서도 동작합니다.
* 외부 이미지 없이 텍스처를 모두 캔버스로 생성합니다.

### ③ 노선 형상
* `js/route.js`의 곡선 반경, 구배(선로 개요도의 ‰ 값), 고가/지하 높이, 건넘선, 아라뱃길 교량을 그대로 사용합니다.
* 구간 코드(`zc`)로 지상·고가역·박스 터널·원형 터널·지하역을 구분합니다.

### ④ 터널과 조명
* **박스형 / 원형 터널** 단면, 중앙 기둥, 터널 조명등과 녹색 표시등. 갱구 벽체의 구멍은 박스 단면과 원형 단면의 교집합으로 만들어 위쪽 모서리가 비어 보이지 않습니다.
* 지하로 들어가면 안개 색·밀도와 노출(tone mapping exposure)이 서서히 바뀌고, 지하역에서는 조금 더 밝게 조정됩니다.
* **전조등**: 머티리얼 셰이더에 전조등 조명을 주입해 터널 벽·바닥·승강장이 하향/상향에 따라 밝아집니다.

### ⑤ 강우와 와이퍼
* 비의 세기는 노선 위치로 정합니다 (`cvRainAt(s)`, 지상 구간 일부에서 강우). 지하와 고가역 지붕 아래(`sheltered`)에서는 0이 됩니다.
* 비가 오면 안개가 짙어지고 조명이 흐려집니다. 유리창에는 빗방울이 생기고, 속도에 따른 바람으로 흘러내리는 방울은 경로를 따라 늘어나며 옅게 사라지는 자국을 남깁니다. 비가 강하면 공중 빗줄기도 그립니다.
* 와이퍼는 창 아래(차체 안) 축에서 회전하며, 창 폭에 맞춰 회전 폭을 조정해 어떤 화면 비율에서도 양 끝까지 닦습니다. `AUTO`는 비의 세기에 따라 주기를 바꿉니다.

### ⑥ 반대편 열차와 선로 표지
* 반대편 열차는 차체 단면(텀블홈·둥근 지붕), 측면 도색, 출입문·창문, 지붕 냉방기, 대차를 갖추며 기존차와 신조차 전면이 번갈아 나옵니다. 행선지 텍스처는 운행 방향이 바뀌면 다시 그립니다.
* 정지위치 표지, 25 m 간격 위치 태그(전조등을 받으면 노랗게 보이도록 약한 발광), 고가역 역명 기둥.

### ⑦ 화질 자동 조절
* 자동 모드는 35 fps 미만일 때만 렌더 해상도를 낮추며 60% 아래로는 내리지 않습니다. 시작 후 5초 동안은 청크를 만드는 중이라 조절을 멈춥니다.
* 시뮬레이터 메뉴 `3D 화질`: 자동 / 선명 100% / 보통 75% / 가벼움 55% (브라우저별 저장).
* 운전실 OSD 캔버스는 1024×473 좌표계를 유지하면서 실제 표시 크기 × `devicePixelRatio`로 그려 큰 화면에서도 글자가 선명합니다.
* GL·오버레이 캔버스는 크기가 실제로 바뀔 때만 다시 설정해 시작 시 깜빡임을 막습니다.

## 2. 순수 Web Audio API 합성 사운드 엔진

브라우저 내장 `AudioContext`를 활용하여 외부 오디오 파일 없이 실시간으로 소리를 합성합니다.

1. **라디오 무전기 PTT 노이즈 (치지직 잡음)**: 화이트 노이즈를 Bandpass 필터(800Hz ~ 3.2kHz)에 통과시켜 무전기 잡음 합성.
2. **COB 통신 비프음 (Beep)**: 비상응답, 운전실통화, 실내/실외방송 버튼을 누를 때 1,200Hz 사인파 비프.
3. **가변 인버터 모터음**: 주행 속도(0~80 km/h)에 비례해 인버터 스위칭 주파수 변조.
4. **레일 이음매 충격음 (`Joint Clack`)**: 25 m 주행마다 타격음(Sawtooth + Lowpass) 2연타.
5. **공압 에어 배기음 (`playAirExhaust`)**: 주차제동 체결/완해, 정차제동 완해 등에서 감압 배기음.
6. **열차 전기혼 경적음 (`playTrainHorn`)**: F#4 (370Hz) + A4 (440Hz) 듀얼 톤.
7. **공기압축기 (`startCompressor` / `stopCompressor`)**: MR이 8.0 bar 이하로 떨어지면 압축기 모터음이 켜지고 10.0 bar에서 꺼집니다.

## 3. 화면 배치 (워크스테이션 그리드)

* CSS Grid로 실물 콘솔 배치를 구성합니다: 좌측 OP2~OP5 선택 패널(세로 전체), 상단 3D 전망, 하단 DU · ADU · OP1.
* **와이드 모니터** (`min-aspect-ratio: 11/5`, 2.2:1 이상): 좌측 패널 / 가운데 3D(세로 전체) / 우측 DU+ADU 위, OP1 아래. 32:9(3:1 이상)에서는 비율을 한 번 더 조정합니다. 좌측 패널은 1080p 배치를 유지한 채 칸에 맞게 확대·축소하고, 운전실 오버레이(OP 탭, 속도 OSD, 메뉴)도 3D 화면 크기에 맞춰 커집니다.
* DU와 ADU는 같은 크기의 모니터처럼 같은 배율로 그리며, 실제 화면 내용 크기에 맞춰 가운데 정렬합니다.
* 이전 버전의 모바일 1분할 / 태블릿 2분할 / PC 3분할 슬롯 뷰포트는 [`/old/`](https://l2l2l2l2.github.io/study/old/)에 남아 있습니다.

## 4. 성능

* DU·ADU 화면 갱신(약 2.7 ms)은 물리 루프 매 프레임이 아니라 **20 Hz**로 실행합니다.
* 3D는 청크 스트리밍과 화질 자동 조절로 부하를 제한합니다.

---

## 5. PointerEvent 기반 연속 물리 드래그

* 마스콘 T바 핸들과 역전기 볼 노브는 `PointerEvent` 기반으로 터치 또는 마우스 드래그 시 실제 레버를 밀고 당기듯이 조작되며, 손을 떼는 순간 가장 가까운 노치로 자동 스냅됩니다.

## 6. 원격 교육 연동 (선택)

* ⚙️ 메뉴 `📡 원격 교육 연동`에서 Supabase URL·키를 입력하면 학생과 교관(OCC 화면)이 연결됩니다. 교관은 종합관제실(OCC) 패널에서 훈련생 상태를 보고 고장(출입문 쇄정 불량, EB 고착, VOBC 고장·통신 이상, TCMS 고장)을 주입하거나 힌트를 보낼 수 있으며, 조작 로그를 CSV로 저장할 수 있습니다.
