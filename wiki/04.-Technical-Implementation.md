# ⚡ 4. 웹 기술 및 아키텍처 (Technical Implementation)

본 시뮬레이터는 외부 라이브러리 의존성 없이 표준 웹 기술(HTML5, Canvas 2D, Web Audio API, SVG)만으로 고성능 3D 시뮬레이션과 물리 음향을 구현했습니다.

---

## 1. 3D 의사(Pseudo-3D) 철도 궤도 렌더링 엔진 (Cab View Simulation)

`claude.html` 및 `index.html`에 탑재된 전면 창밖 선로 렌더링 시스템은 무거운 WebGL/Three.js 없이 순수 Canvas 2D 연산만으로 고전 아케이드 방식의 3D 원근 투영을 수행합니다.

### ① 실물 사진 창틀 마스킹 (`cvWindowPath` & `destination-out`)
* 실제 운전실 사진(`cab_view.png`)에서 기관실 전면 유리창 개구부 좌표를 다각형 패스(`cvWindowPath`)로 정의합니다.
* 캔버스 복합 연산(`destination-out`)을 통해 창 영역만 완벽히 도려낸 프레임 캔버스(`CV_FRAME`)와 배경 원경 캔버스(`CV_BACK`)를 사전에 캐싱하여 렌더링 부하를 극소화합니다.

### ② 3차원 투영 파이프라인
* **곡률(`cvCurv`) 및 구배(`cvGradeAt`) 함수**: 주행 거리 $s$에 따라 복합 삼각함수로 실시간 우/좌 곡선 및 상/하 오르막·내리막 구배를 계산합니다.
* **선형 프리컴퓨트 버퍼 (`cvLat`, `cvElev`)**: 최대 260m 전방까지 1m 단위로 궤도의 횡변위와 표고를 사전 계산하여 저장합니다.
* **투영 계산식 (`cvProj`, `cvScale`)**:
  $$X_{screen} = V_{pX} + \frac{Focal}{Distance} \times (u + L) + \text{ShakeX}$$
  $$Y_{screen} = Horizon + \frac{Focal}{Distance} \times (v + E) + \text{ShakeY} + \text{Pitch}$$

### ③ 궤도 구조물 및 주변 환경
* **레일 & 침목**: 1,435mm 표준 궤간 레일 및 0.62m 간격의 침목 위상(`trackTiePhase`)을 주행 속도와 동기화하여 연속 렌더링.
* **도상 자갈 및 전차선 가선주**: 50m 간격으로 배치된 가선 기둥과 전차선(Catenary Wire) 원근 투영.
* **인천 2호선 8대 역 승강장**: 1,500m 노선 주기에 따라 승강장 스크린도어, 기둥, 조명, 역명판 동적 생성.
* **터널 및 기상 연동**: 780m 지점 터널 진입 시 조도 감쇄(`ambient`) 및 아치 조명 렌더링, 강우 시 빗방울 물리학 및 와이퍼 닦임 연동.

## 2. 순수 Web Audio API 합성 사운드 엔진

브라우저 내장 `AudioContext`를 활용하여 외부 오디오 파일 다운로드 없이 100% 실시간 물리 음향을 합성합니다.

1. **라디오 무전기 PTT 노이즈 (치지직 잡음)**:
   * 마이크를 누르고 있는 동안 화이트 노이즈 버퍼를 Bandpass 필터(800Hz ~ 3.2kHz)에 통과시켜 실제 열차 무전기 특유의 지직거리는 잡음을 실시간 합성.
2. **COB 통신 비프음 (Beep)**:
   * 비상응답, 운전실통화, 실내/실외방송 버튼을 누를 때 1,200Hz 단음 사인파 비프 출력.
3. **가변 인버터 모터음**:
   * 열차 주행 속도(0~80 km/h)에 비례하여 인버터 스위칭 주파수를 실시간 변조하여 가속/감속 시 모터 구동음 연동.
4. **레일 이음매 충격음 (`Joint Clack`)**:
   * 25m 주행마다 차륜이 레일 이음매를 통과할 때 발생하는 둔탁한 타격음(Sawtooth + Lowpass) 2연타 출력.
5. **공압 에어 배기음 (`playAirExhaust`)**:
   * 주차제동 체결/완해 시 1.0초간 공압이 분출되는 "치이이이익~~~~" 감압 배기음.
6. **열차 전기혼 경적음 (`playTrainHorn`)**:
   * 실제 전동차 듀얼 톤: F#4 (370Hz)와 A4 (440Hz) 복합 화음 오실레이터 동시 발진.

## 3. 모바일 동적 뷰포트 (100dvh) 및 화면 최적화

* **`100dvh` + `--app-height` 듀얼 연동**: 모바일 브라우저 주소창이나 하단 바가 나타나거나 사라져도 하단 툴바가 가려지지 않도록 CSS 변수와 뷰포트를 실시간 보정합니다.
* **Flex 컨테이너 기반 가변 레이아웃**: 상단 HUD 고정, 패널 영역 독립 스크롤, 하단 툴바 상시 노출.

---

## 4. 반응형 멀티 슬롯 뷰포트 아키텍처 (2분할 / 3분할)

* **모바일 모드 (< 768px)**: 단일 슬롯(`slot-left`) 기반 1열 뷰.
* **태블릿 / 폴더블 (>= 768px)**: 2분할 듀얼 뷰포트 (`slot-left`, `slot-right`) 및 중복 패널 선택 시 자동 맞바꿈(Smart Swap) 지원.
* **PC / 와이드 모니터**: **3분할 트리플 뷰포트** 지원으로 OP1(운전대/전면뷰), OP2~OP3(주요 조작반), OP4~OP5(보조 조작반)를 한 화면에서 넓게 실습 가능.

---

## 5. PointerEvent 기반 연속 물리 드래그

* 마스콘 T바 핸들과 역전기 볼 노브는 `PointerEvent` 기반으로 터치 또는 마우스 드래그 시 실제 레버를 밀고 당기듯이 부드럽게 조작되며, 손을 떼는 순간 가장 가까운 노치로 자동 스냅됩니다.
