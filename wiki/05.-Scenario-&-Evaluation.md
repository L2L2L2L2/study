# 🎯 5. 시나리오 및 평가 엔진 (Scenario & Evaluation)

본 시뮬레이터는 학습자의 숙련도를 단계별로 높일 수 있도록 자유 테스트 모드와 3가지 훈련 모드, 커스텀 시나리오 생성 기능을 지원합니다.

---

## 0. 자유 조작 및 시스템 테스트 모드 (FREE Mode / 기본 실행 모드)

* **목적**: 시뮬레이터 최초 접속 시 기본으로 진입하는 샌드박스 탐색 모드입니다. 특정 시나리오 순서에 얽매이지 않고 운전대 전체 장치를 자유롭게 조작하며 인터록, 계기판(압력 게이지, 속도계), 사운드 및 햅틱 반응을 테스트할 수 있습니다.
* **주요 특징**:
  * **오조작 경고 없음**: 시나리오 순서와 상관없이 어떠한 버튼, 스위치, 레버를 조작해도 "잘못된 조작" 경고창이나 에러음이 발생하지 않습니다.
  * **자유로운 시스템 테스트**: 마스터키 투입, 역전기 전환, 마스콘 제어, 비상제동 체결/복귀, 각종 차단기 및 바이패스 스위치 등 모든 물리 장치와 인터록 반응을 완전하게 체험할 수 있습니다.
  * **언제든지 전환 가능**: 하단 네비게이션의 **[📋 시나리오 선택]** 팝업에서 언제든 원하는 시나리오를 선택하여 실습을 시작하거나, 다시 **[🛠️ 자유 모드로 전환]**하여 자유 탐색으로 돌아올 수 있습니다.

## 기본 탑재 시나리오

| ID | 시나리오 | 주입 고장 | 절차 |
| :--- | :--- | :--- | :--- |
| `SCN_PARK_BRAKE_BP` | 1. 주차제동 완해 불능 시 주차제동BP 취급 | `PARK_REL_FAIL` (MR 정상, 완해 후에도 역행회로 미복귀) | ① 주차제동체결 → ② 주차제동완해 (복귀 안 됨 확인) → ③ OP5 주차제동BP `바이패스` |
| `SCN_MR_LEAK_BP` | 2. MR 공기누설(4.0~6.0 bar) 시 주공기BP 취급 및 회송 | `MR_LEAK` (6.0 bar 미만 비상제동 + 역행 차단) | ① 관제 보고 → ② 비상완해 보호커버 열림 → ③ OP3 비상제동완해 → ④ OP5 주공기BP `바이패스` → ⑤ 최근역 정차 → ⑥ 출입문 열림(승객 하차) → ⑦ 하차 완료 보고 → ⑧ 출입문 닫힘 → ⑨ 마스콘 역행(회송 출발) |
| `SCN_MR_LEAK_RESCUE` | 3. MR 4.0 bar 미만(비상·주차제동 체결) 시 구원연결 요청 | `MR_LEAK_SEVERE` (비상제동 + 주차제동 자동 체결) | ① 관제에 구원연결 요청 보고 → ② OP3 구원운전 `구원` (구원연결) |
| `SCN_TCMS_CU_RESET` | 4. TCMS 통신고장(MC1 CU 통신고장) 시 CU 스위치 재투입 | `TCMS_FAIL` (ADU TCMS 적색, DU 노란 바탕) | ① MC1 CCUCB·CCUDOCB·CCUDICB 차단 → ② MC1 복귀 → ③ MC2 차단 → ④ MC2 복귀 (단계 안의 세 스위치는 순서 무관) |

* 시나리오 객체의 `faults` 배열에 고장 ID를 넣으면 시나리오 시작 시 해당 고장이 주입됩니다. `setup`으로 시작 운전 상태(운전모드·제어키·전후진)를 지정합니다.
* **관제 보고 단계 (`type: "REPORT"`)**: HUD에 **[📡 관제 보고]** 버튼이 나타나며, 누르면 보고 문구가 기록되고 관제 응답이 무전(TTS)으로 나옵니다.
* **역 정차 단계 (`type: "ARRIVE"`)**: 단계 시작 위치에서 50 m 이상 운행한 뒤 역 정차점 ±5 m에 정차하면 자동으로 완료됩니다.
* `allOf`: 여러 부품을 순서 상관없이 모두 `expectedState`로 만들면 단계가 완료됩니다.
* `allowDriving: true`인 시나리오에서는 마스콘·전후진제어기·제어키·운전모드 조작을 오조작으로 치지 않습니다.
* 역행회로 차단 조건은 [운전 취급 매뉴얼 7절](03.-Operating-Manual#7-주차제동-체결-시-역행회로-차단-및-주차제동bp-취급)을 참고하십시오.

## 1. 실습 훈련 모드 (PLAY Mode)

* **목적**: 초심자 또는 훈련생이 비상 절차를 자유롭게 조작하며 익히는 학습 모드입니다.
* **주요 기능**:
  * **스마트 타겟 하이라이트**: 다음으로 조작해야 할 부품의 테두리가 노란색 점선으로 부드럽게 깜빡이며(Pulse 효과) 위치를 안내합니다.
  * **실시간 지시문 안내**: 상단 HUD에 현재 취급해야 할 동작 문구가 표시됩니다. (예: `비상 상황 발생! 빨간색 비상제동체결 버튼을 누르십시오.`)
  * **자동 패널 전환**: 목표 부품이 현재 보이지 않는 패널에 위치한 경우, 해당 패널로 자동으로 뷰를 전환해 줍니다.
  * **💡 힌트 보기**: 하단 툴바의 힌트 버튼 클릭 시 목표 부품을 즉시 강조합니다.

## 2. 실전 평가 모드 (EXAM Mode)

* **목적**: 실제 시험 환경과 동일하게 시각적 보조(힌트, 테두리 깜빡임)를 제거하고 시간과 정확도를 측정하는 모드입니다.
* **주요 기능**:
  * 타겟 하이라이트 효과 완전 비활성화
  * **오조작 감점 시스템**: 규정 순서와 다른 부품을 누르거나 잘못 조작할 경우, 에러 버저음 출력과 함께 오조작 횟수(`mistakesCount`)가 누적됩니다.
  * **실시간 스톱워치**: 훈련 시작부터 완료까지 소요된 시간을 1초 단위로 측정합니다.
  * **최종 성적 리포트 카드 (Modal)**:
    * **PASSED / FAILED** 등급 스탬프 부여
    * 총 소요 시간, 오조작 횟수, 100점 만점 기준 최종 달성 점수 집계

```

│         🎉 훈련 절차 완료 리포트         │
├────────────────────────────────────────┤
│  최종 평가 결과 :  [ PASSED ]           │
│                                        │
│  소요 시간 : 18초                        │
│  오조작 횟수 : 0회                      │
│  달성 점수 : 100점                      │
├────────────────────────────────────────┤
│  [ 닫기 ]            [ 다시 연습하기 ]   │
└────────────────────────────────────────┘
```

## 3. 동작 녹화 모드 (REC Mode)

* **목적**: 교관이나 관리자가 시뮬레이터 화면에서 부품들을 직접 조작하는 것만으로 **새로운 훈련 시나리오를 코딩 없이 즉석에서 제작**할 수 있는 저작 도구(Authoring Tool)입니다.
* **사용 방법**:
  1. 모드 선택 메뉴에서 **[🔴 동작 녹화]**를 선택합니다.
  2. 상단에 붉은색 레코딩 바가 활성화됩니다.
  3. 교관이 원하는 순서대로 부품을 조작합니다. (예: 마스터키 ON ➔ 역전기 F ➔ 마스콘 P2 투입)
  4. 부품 조작 시마다 팝업이 뜨며, 교육생에게 보여줄 **안내 문구(Instruction)**와 **연동할 제동통 공기압(BC, 0.0~4.0 bar)**을 입력하고 저장합니다.
  5. 모든 단계가 끝나면 **[녹화 완료 및 저장]**을 누르면 시나리오가 완성되며, 즉시 시나리오 목록에 등록되어 실습 및 평가에 활용할 수 있습니다.
