# 🕹️ 2. 조작반별 상세 명세 (Panel Specifications)

본 시뮬레이터는 실제 도시철도 전동차 운전실의 5대 주요 조작반(OP1~OP5)과 DU·ADU 표시 화면, 차단기반을 재현합니다.

> 이 문서는 메인 버전(`/`, 인천 2호선 3D) 기준입니다. 이전 단일 파일 버전은 [`/old/`](https://l2l2l2l2.github.io/study/old/)에 보관되어 있습니다.

## 화면 배치 (실물 콘솔 워크스테이션)

실제 운전실 콘솔처럼 한 화면에 모든 장치를 배치합니다.

```
┌──────────────┬──────────────────────────────────────────────────┐
│ [OP2~OP5]    │            [3D 전면 전망]                         │
│  선택 패널   │  - 운전실 창틀 오버레이 + 노치·속도 OSD          │
│  (탭 전환)   │  - ⚙️ 시뮬레이터 메뉴                              │
│              ├────────────────┬────────────────┬────────────────┤
│  [차단기]    │      [DU]      │     [ADU]      │     [OP1]      │
│  [📡 OCC]    │                │                │ 마스콘·역전기  │
└──────────────┴────────────────┴────────────────┴────────────────┘
```

* **기본 배치**: 좌측 열에 OP2~OP5 중 하나를 선택해 표시(시작 시 OP4), 상단에 3D 전면 전망, 하단에 DU · ADU · OP1을 나란히 배치합니다. OP1은 항상 표시되며 칸에 맞게 크기가 조절됩니다.
* **와이드 모니터 (가로세로비 2.2:1 이상, 21:9·32:9)**: 좌측 OP2~OP5, 가운데 3D 전망(세로 전체), 우측 상단 DU+ADU, 우측 하단 OP1. 16:9 모니터의 브라우저 창(약 2.02:1)은 기본 배치를 유지합니다.
* 좌측 패널 탭 옆의 **[차단기]** 버튼은 차단기반 팝업을, **[📡 OCC]** 버튼은 종합관제실(교관) 패널을 엽니다.

## 3D 전면 전망 (Front Cab View)

* **Three.js 3D 장면**: 인천 2호선 201 검단오류 ~ 227 운연 실제 노선을 하선·상선 양방향으로 주행합니다. 열차 주변 구간만 생성하며, 운전실 사진(`cab_view.png`)의 창틀 오버레이 너머로 장면이 보입니다.
* **하단 OSD 주행 정보 태그**: `| F | P2 | 20 Km/h |` 형식으로 전후진 방향, 마스콘 노치, 현재 속도를 표시합니다.
* **터널**: 박스형·원형 단면과 갱구 벽체, 터널 조명. 지하 구간에서는 장면이 어두워지고 전조등이 벽·바닥·승강장을 비춥니다.
* **강우와 와이퍼**: 노선 위치로 정해진 지상 구간에서 비가 내리고, 유리창 빗방울은 흘러내리며 옅은 자국을 남깁니다. 지하와 고가역 지붕 아래에서는 비가 맞지 않습니다. 팬터그래프식 와이퍼는 창 아래 축을 중심으로 창 폭 전체를 닦으며 OP4 와이퍼 스위치를 따릅니다.
* **전조등**: OP2 전조등 스위치에 따라 하향/상향/소등. 상향은 더 밝고 멀리 비춥니다.
* **반대편 열차**: 기존차·신조차 전면이 번갈아 지나가며, 행선지 표시가 진행 방향(검단오류/운연)을 따릅니다.
* **선로 표지**: 표준도면 기준 정지위치 표지(PSD 측면 400×400 mm 검정 표지, 궤도 중앙 반사 삼각 표지), 25 m 간격 노란 위치 태그, 고가역 PSD 시작점의 역명 기둥.
* **3D 화질**: 기본은 자동(35 fps 미만일 때만 해상도를 낮추며 60% 아래로는 내리지 않음). 시뮬레이터 메뉴의 `🖥️ 3D 화질`에서 자동 / 선명 100% / 보통 75% / 가벼움 55%를 고를 수 있고 브라우저별로 기억합니다.

## OP1 : 운전실 주 제어반 (Main Driving Console)

```
┌──────────────────────────────────────────────────────────┐
│  [방송 및 통화용 마이크 & COB]   [주간제어기(마스콘)]      │
│  - PTT 무전기 라디오 노이즈      - T-bar 원핸들 (EB ~ P4) │
│  - 비상응답/통화/방송 비프음     - 제어키 (OFF / ON)      │
│  - 마이크·운전실 음량            - 전후진제어기 (F/N/R)   │
│  [출입문 스위치]                 - 축전지 ON / OFF        │
│  - 좌측열림(커버)/닫힘/우측열림                           │
└──────────────────────────────────────────────────────────┘
```

### 1. 방송 및 통화용 마이크 & COB 통신 장치
* **마이크 유닛**: PTT 터치 조작 시 무전 교신 **"치지직" 라디오 노이즈(Radio Static)** 출력. 마이크 음량·운전실 음량 볼륨 노브.
* **COB 통신 버튼**: 비상응답, 운전실통화, 실내방송, 실외방송 4대 버튼. 누를 때마다 **전자 비프음(Beep)** 출력.

### 2. 출입문 조작 스위치
* **좌측열림(보호커버) / 출입문 닫힘 / 우측열림** 버튼 세트.
* 출입문이 열리면 OP2의 [출입문] 녹색 표시등이 소등되고, 닫히면 점등됩니다. (출입문이 열려 있으면 가속이 차단됨)

### 3. 주간제어기 (Master Controller) 메인 프레임
* **T자형 원핸들 (T-bar Handle)**:
  * **노치 스케일**: `EB`(비상제동, 적색) ➔ `B7` ~ `B1`(상용제동 7단계) ➔ `N`(중립, 녹색) ➔ `P1` ~ `P4`(역행 4단계).
  * 역행 목표 속도: P1 25 / P2 45 / P3 65 / P4 80 km/h.
  * 터치 탭 또는 드래그로 실제 레버처럼 슬라이드 조작 가능.
* **제어키 (`SW_MASTER_KEY`)**: OFF / ON 2단.
  * 운전모드가 `OFF`일 때는 `ON`으로 회전할 수 없음.
  * 역전기가 `F` 또는 `R`에 있을 때는 `OFF`로 회전할 수 없음 (중립 N 필수).
* **역전기 (Reverser)**: 대형 유광 블랙 구형 볼 노브. **F**(전진) / **N**(중립) / **R**(후진).
* **축전지 ON / OFF** 버튼.

## OP2 : 상부 표시등 조작반 (Upper Indicators)

### 1. 5대 인디케이터 표시등 (Indicator Bar)
| 표시등 명칭 | 렌즈 색상 | 점등 조건 및 역할 |
| :--- | :---: | :--- |
| **출입문** | 🟢 녹색 | 전동차 전체 출입문이 닫히고 쇄정되었을 때 점등 (기본 점등) |
| **제동체결** | 🔴 적색 | OP3 비상제동체결 버튼 체결 시, 또는 마스콘 EB 투입 시 점등 |
| **선두차지정** | 🟡 황색 | `운전모드(RM/FM/ATPM) + 키(ON) + 역전기(F/R)` 3중 조건 충족 시 점등 |
| **비상제동차단** | 🔴 적색 | OP3 비상제동완해 조작 완료 시 점등 |
| **커플링** | 🟢 녹색 | 전동차 병결/분리 상태 모니터링 |

### 2. 조작 스위치
* **전면창 히터 (`SW_WINDOW_HEATER`)**: 자동(AUTO) / 수동(MANUAL) 2단 로터리.
* **전조등 (`SW_HEADLIGHT`)**: 원격(REMOTE) / 자동(AUTO) / 소등(OFF) / 상향(HIGH) / 하향(LOW) 5단 로터리. 3D 전망에서 원격·자동·하향은 하향등, 상향은 상향등, OFF는 소등.
* **전기혼 (`SW_ELEC_HORN`)**: 누르면 F#4(370 Hz) + A4(440 Hz) 듀얼 톤 경적.

## OP3 : A필러 긴급 제동 조작반 (A-Pillar Emergency Brake Panel)

기관사 좌측 기둥(A-Pillar)에 위치하며, 비상제동 및 긴급 구원 취급을 위한 특수 스위치로 구성됩니다.

| 부품 ID | 스위치 명칭 | 형태 및 특징 |
| :--- | :--- | :--- |
| `SW_EMG_STOP` | **비상제동체결** | 3-Arrow 각인 적색 버섯형(E-Stop) 래치 버튼. 누르면 체결(BC 4.0 bar, [제동체결] 점등), 시계방향 회전 시 복귀 |
| `SW_FORCE_REL` | **강제완해** | 원형 적색 푸시버튼. 제동 고착 시 제동통 공기를 강제 배출하여 완해(BC 0.0 bar) |
| `SW_EMG_RELEASE` | **비상제동완해** | **투명 아크릴 안전커버(`SW_EMG_COVER`)** + 내부 적색 푸시버튼. 비상제동 불완해 시 강제 완해(BC 0.0 bar, [비상제동차단] 점등) |
| `SW_WIRELESS_MODE` | **무인모드 (ATO)** | **투명 아크릴 안전커버(`SW_WIRELESS_COVER`)** + 내부 녹색 푸시버튼. 4대 조건 충족 시 **3초 롱프레스**로 무인운전 인가 |
| `SW_ATP_REV` | **ATP후진** | 투명 안전커버(`SW_ATP_COVER`) + 내부 2단 로터리 스위치 (OFF / ON). ON이면 ADU `ATP Reverse` 황색 표시 |
| `SW_LOW_SPEED` | **저속도** | 2단 로터리 스위치 (정상 / 바이패스) |
| `SW_PARK_SET` | **주차제동체결** | 원형 녹색 푸시버튼 (공압 배기음, DU PB 칩 연동) |
| `SW_PARK_REL` | **주차제동완해** | 원형 적색 푸시버튼 (공압 배기음, DU PB 칩 연동) |
| `SW_ROOM_LIGHT` | **실내등** | 3단 로터리 스위치 (수동 / 자동 / 비상등) |
| `SW_RESCUE_DRIVE` | **구원운전** | 3단 로터리 스위치 (구원 / 정상 / 비상) |

## OP4 : 메인 계기 & 운전모드 (Main Gauges & Drive Mode)

공기 압력 감시, 운전모드 선택, 보조 바이패스를 설정하는 패널입니다. 시뮬레이터를 열면 좌측 패널에 OP4가 먼저 표시됩니다.

### 1. 공기 압력계 (MR & BC 듀얼 게이지)
* **MR (주공기통 압력, 적색 바늘)**: 정상 범위 8.0~10.0 bar.
  * 제동으로 BC에 들어간 공기만큼 MR이 감소 (BC 변화를 1초 지연으로 반영).
  * 8.0 bar 이하에서 **공기압축기(CM) 기동** → 10.0 bar까지 충기 후 정지 (약 33초, 보통 2~3개 역 운행마다 한 번). 동작 중 DU `CMG` 파란색 점등 및 압축기 소리.
* **BC (제동통 공기압력, 흑색 바늘)**:
  * 완해 / 타행(N) / 역행(P1~P4): **`0.0 bar`**
  * 정차제동(HB): **`2.0 bar`**
  * 상용 제동: `B1`(2.3 bar), `B2`(2.7 bar), `B3`(3.0 bar), `B4`~`B7`(4.0 bar)
  * 비상 제동 (EB 노치, 비상제동체결 버튼, HCR 비상제동): **`4.0 bar`**

### 2. 운전 모드 4단 로터리 스위치 (`SW_DRIVE_MODE`)
* **FM (Full Manual / 완전 수동)**: 90° 좌회전. 기관사 완전 수동 조작 (최대 80 km/h). ADU 제한속도 표시 없음.
* **RM (Restricted Manual / 제한 수동)**: 45° 좌회전. **허용속도 15 km/h** — 15~17 km/h가 5초 이상 지속되거나 18 km/h 이상이면 비상제동 체결.
* **OFF (운전 모드 정지 / 무인운전 대기)**: 중앙 0°. **운전대 전체 잠금 (키 ON 불가, 역전기/마스콘 조작 불가)**. 무인운전 중이 아니면 HCR 비상제동(EB+HB) 체결.
* **ATPM (차상 신호 수동 운전)**: 45° 우회전. 차상 신호 연동 수동 모드. ADU에 노선 제한속도 표시.

### 3. 보조 제어 스위치
* **와이퍼 5단 로터리 스위치**: `OFF` / `AUTO`(비가 오면 자동 작동) / 간헐(`INT`) / 저속(`SLOW`) / 고속(`FAST`)
* **장애물 감지 스위치**: 정상 / 바이패스
* **출입문 스위치 (`SW_DOOR_BYPASS`)**: 정상 / 바이패스 (바이패스 시 DU ADBS 칩 점멸)
* **출입문 히터 스위치**, **공기질 개선 스위치**(수동 / 정지 / 자동), 예비 로터리·버튼

## OP5 : 보조 조작반 (Auxiliary Panel)

차상 신호(VOBC) 리셋 및 고전압 차단기/바이패스 스위치가 배치된 조작반입니다.

### 1. VOBC 리셋 스위치 (`SW_VOBC_RESET`)
* 노란색 원형 푸시버튼. 누르는 시간에 따라 동작이 달라집니다.
  * **2~3초간 누름**: 활성 VOBC를 반대쪽(VOBC1 ↔ VOBC2)으로 전환.
  * **5~7초간 누름**: 전·후부 VOBC 전체 리셋 → VOBC1 활성, **`POSITION LOST`** 발생. RM 모드로 25 m 위치 태그 2개를 통과하면 해소.
  * 7초 초과 시 타임아웃 경고 발생.
* 활성 VOBC는 DU의 VOBC·Mc 표기 색과 ADU의 Ⓐ 마크에 함께 표시됩니다.

### 2. 하부 바이패스 및 차단기 스위치군
* **언커플링 스위치**: 연결기 분리 제어
* **고속도차단기동작 (HB) 스위치**: 주 회로 고속도 차단기 투입/차단
* **주공기 바이패스 (MR BP)**: 공압 누기 시 비상 공급 바이패스
* **PWM 차단 스위치**: 추진 인버터 PWM 제어 신호 차단
* **살사시험 스위치**: 모래 분사 장치 동작 시험
* **절연구간 스위치**: 사구간(Dead Section) 통과 준비
* **주차제동 바이패스 (PB BP)**: 주차제동 불완해 시 강제 완해 바이패스

## DU (Display Unit)

* **상태 표시줄**: `운전모드 | HB | EB | PB | ADC/ADBS | 다음역/종착역`이 같은 높이의 한 줄로 이어져 표시됩니다.
  * 모드 칩: FM / RM / ATPM, 무인운전 중에는 파란색 두 줄 **"Driver less"**.
  * HB(정차제동) / EB(비상제동) / PB(주차제동) 칩: 체결 중에만 점등, 평소에는 회색.
  * ADC(All Door Close): 모든 문이 닫히면 파란색, 하나라도 열리면 적색 점멸. ADBS(출입문 바이패스): 바이패스 시 적색 바탕 흰 글씨로 점멸.
  * 다음역·종착역: FM·RM에서는 빈칸.
* **편성 표시**: Mc1·Mc2가 붙어 있는 형태. 진행 방향 화살표는 역전기가 F/R일 때만 표시되며 하선은 Mc1 쪽, 상선은 Mc2 쪽을 향합니다.
* **VOBC 표시**: 활성 VOBC는 녹색 글씨, 비활성은 흰 글씨. 운전모드 OFF(HCR)에서는 VOBC 미선택.
* **이벤트 메시지**: 운전 중인 운전실 이름(하선 MC1, 상선 MC2)으로 표시. 예: `MF HCR 비상제동체결`, `MCF MC1 VOBC RESET EB`.
* **CMG**: 공기압축기 동작 중 파란색 점등.
* 실물 화면과 같은 곡선 엠블럼 로고("Fly" / "Incheon").
* DU·ADU 화면은 성능을 위해 매 프레임이 아니라 20 Hz로 갱신합니다.

## ADU (Automatic Driving Unit)

* **속도계**: 현재 속도 바늘. 흰색 호(arc)로 현재 제한속도를 표시 — RM은 15 km/h, ATPM·무인운전은 노선 설계속도를 45 / 60 / 80 단계로 표시, FM은 제한속도 호 없음. 제한속도를 넘으면 바늘과 중심이 적색.
* **Target Point**: 다음 정지위치까지 거리 (FM에서는 빈칸).
* **Door Enable**: RM·FM은 `Both`, 그 외에는 `Right`.
* **Next / Final Platform**: 역 번호 + 방향 코드(하선 A / 상선 B). FM에서는 빈칸.
* **ATP Reverse**: 평소 회색, OP3 ATP후진 스위치 ON 시 황색.
* Train Length, Dwell Time, PSD / Train Door 상태 행.

## 차단기반 (Circuit Breaker Panel)

좌측 패널 탭 옆의 **[차단기]** 버튼을 누르면 팝업으로 열리며, 화면에 맞게 스크롤 없이 축소 표시됩니다. 각 차단기는 눌러서 ON/OFF를 바꿀 수 있고, `CB_<이름>` 컴포넌트로 등록되어 시나리오 단계로 사용할 수 있습니다.

| 탭 | 구성 |
| :--- | :--- |
| **주 차단기(기존차)** | ABB S281 UC 차단기 열, Schneider CMCB(IOF 보조접점 블록), RCBO, 비상문 바이패스 |
| **주 차단기(신조차)** | ABB 패널 5열: 보조접점 + 1·2·3극 차단기, RCBO. 노출된 홈 안의 검정 레버와 각인된 ON/OFF |
| **냉난방 스위치** | Schneider C60N 계열 MX+OF 모듈, 타이바(tie bar)에 연결된 ABB형 손잡이와 흰 글씨, 극 위에 라벨 |

* 기존차와 신조차 탭에서 **이름이 같은 차단기는 상태가 연동**됩니다 (SPARE는 각각 독립).
* 손잡이와 타이바에는 접힌 면의 명암(ON일 때 위쪽 30%, OFF일 때 약 70% 위치)을 넣어 입체감을 표현하고, 명판 라벨은 칸 크기에 맞춰 15px~10.5px로 조정됩니다.
