# 🕹️ 2. 조작반별 상세 명세 (Panel Specifications)

본 시뮬레이터는 실제 도시철도 전동차 운전실의 5대 주요 조작반(OP1~OP5)을 완벽하게 재현합니다.

---

## OP1 : 운전실 주 제어반 (Main Driving Console)
운전실의 핵심 주행 제어 장비들이 집약된 메인 컨트롤 콘솔입니다.

```
┌──────────────────────────────────────────────────────────┐
│  [전면 운전실 3D 뷰 모니터]   [주간제어기(마스콘)]         │
│  - 실물 사진 창틀 마스킹      - T-bar 원핸들 (EB ~ P4)    │
│  - 3D 궤도/역/터널/우천 연동  - 전후진제어기 (F / N / R)   │
│  - 하단 태그: | F | P2 | 20 Km/h |                       │
│  [통화용 마이크 & COB 장치]                               │
│  - PTT 무전기 라디오 노이즈    - 출입문 개폐 (열림/닫힘)   │
│  - 비상응답/통화 등 비프음     - 출입문 상태 표시등        │
└──────────────────────────────────────────────────────────┘
```

### 0. 전면 운전실 주행 뷰 모니터 (Front Cab View Monitor)
* **위치**: OP1 좌측 열 최상단 (방송 및 통화용 마이크 바로 윗부분)
* **너비 일치**: 사용자 요청에 따라 운전대(마스콘 프레임)와 좌측 열(운전실뷰, 마이크, 출입문 버튼)의 너비를 완벽하게 동기화했습니다.
* **실물 사진 마스킹 및 3D 합성**:
  * 실제 운전실 사진(`cab_view.png`)의 전면 유리창 영역만 마스킹 추출(`cvWindowPath`)하여 차체 내부 프레임 너머로 3차원 선로가 펼쳐집니다.
  * **하단 OSD 주행 정보 태그**: 깔끔하고 직관적인 `| F | P2 | 20 Km/h |` 포맷으로 실시간 전후진 방향, 마스콘 노치, 현재 주행 속도(km/h)를 표시합니다. (무인운전 시 `| ATO 무인 | 60 Km/h |`)
* **3D 의사(Pseudo-3D) 주행 시뮬레이션**:
  * **역행 및 주행**: P1~P4 투입 시 모터 인버터 가변 주파수 구동음과 함께 시속 0에서 25/45/65/80 km/h까지 가속.
  * **인천 2호선 8대 역 승강장**: 검단오류, 왕길, 검단사거리, 마전, 완정, 독정, 검암, 주안국가산단 승강장 진입/통과.
  * **터널 및 기상 연동**: 터널 진입 시 자연스러운 암전 및 벽면 아치 조명, 강우 구간 물방울 및 와이퍼 빗방울 닦임 물리 효과.
  * **차체 진동 & 레일 이음매 충격음**: 주행 속도에 비례한 차체 진동, 캔트 롤링(Sway) 및 25m 주기 레일 이음매 충격음(`Joint Clack`) 출력.

### 1. 방송 및 통화용 마이크 & COB 통신 장치
* **마이크 유닛**:
  * PTT 터치 조작 시 실제 무전 교신 시 발생하는 **"치지직" 라디오 노이즈(Radio Static)** 사운드 출력.
* **COB 통신 버튼**:
  * 비상응답, 운전실통화, 실내방송, 실외방송 4대 버튼 탑재.
  * 버튼을 누를 때마다 맑은 **전자 비프음(Beep)** 피드백 출력.

### 2. 출입문 조작 스위치
* **출입문 열림 / 닫힘**:
  * 전동차 좌·우 출입문 개폐를 제어하는 버튼 세트.
  * 출입문이 열리면 OP2의 [출입문] 녹색 인디케이터가 소등되고, 닫히면 점등됩니다. (출입문이 열려 있으면 가속이 차단됨)

### 3. 주간제어기 (Master Controller) 메인 프레임
* **T자형 원핸들 (T-bar Handle)**:
  * 좌측으로 길게 뻗은 인체공학적 T자형 손잡이.
  * **노치 스케일**: `EB`(비상제동, 적색) ➔ `B7` ~ `B1`(상용제동 7단계) ➔ `N`(중립, 녹색) ➔ `P1` ~ `P4`(역행 4단계).
  * 터치 탭 또는 마우스/손가락 드래그(Drag)로 실제 기계식 레버처럼 슬라이드 조작 가능.
* **역전기 (Reverser)**:
  * 우측 독립 트랙에 대형 유광 블랙 구형 볼 노브 탑재.
  * **F**(전진) / **N**(중립, 녹색) / **R**(후진) 3단계 제어.

## OP2 : 상부 표시등 및 운전모드 조작반 (Upper Indicators & Mode Panel)

운전대 전면 상부에 위치하여 열차의 핵심 운전 모드를 설정하고 상태를 시각적으로 감시합니다.

### 1. 운전 모드 4단 로터리 스위치 (`SW_DRIVE_MODE`)
* **FM (Full Manual / 완전 수동)**: 90° 좌회전. 기관사 완전 수동 조작 모드 (최대 80 km/h).
* **RM (Restricted Manual / 제한 수동)**: 45° 좌회전. 기지 구내 및 비상용 제한 수동 모드 (**최고속도 25 km/h 자동 제한**).
* **OFF (운전 모드 정지 / 무인운전 대기)**: 중앙 0°. **운전대 전체 잠금 (키 ON 불가, 역전기/마스콘 조작 불가)**.
* **ATPM (차상 신호 수동 운전)**: 45° 우회전. 차상 신호 연동 수동 모드.

### 2. 제어키 (Master Key) 2단 로터리 스위치 (`SW_MASTER_KEY`)
* **OFF / ON** 2단 절체.
* **인터록 규정**:
  * 운전모드가 `OFF`일 때는 `ON`으로 회전할 수 없음.
  * 역전기가 `F` 또는 `R`에 있을 때는 `OFF`로 회전할 수 없음 (중립 N 필수).

### 3. 전면창 히터 2단 로터리 스위치 (`SW_WINDOW_HEATER`)
* **자동 (AUTO)**: 우천 시 와이퍼 및 전면창 히터 자동 연동.
* **수동 (MANUAL)**: 수동 가동 모드.

### 4. 5대 인디케이터 표시등 (Indicator Bar)
| 표시등 명칭 | 렌즈 색상 | 점등 조건 및 역할 |
| :--- | :---: | :--- |
| **출입문** | 🟢 녹색 | 전동차 전체 출입문이 닫히고 쇄정되었을 때 점등 (기본 점등) |
| **제동체결** | 🔴 적색 | OP3 비상제동체결 버튼 체결 시, 또는 마스콘 EB 투입 시 점등 |
| **선두차지정** | 🟡 황색 | `운전모드(RM/FM/ATPM) + 키(ON) + 역전기(F/R)` 3중 조건 충족 시 점등 |
| **비상제동차단** | 🔴 적색 | OP3 비상제동완해 조작 완료 시 점등 |
| **커플링** | 🟢 녹색 | 전동차 병결/분리 상태 모니터링 |

## OP3 : A필러 긴급 제동 조작반 (A-Pillar Emergency Brake Panel)

기관사 좌측 기둥(A-Pillar)에 위치하며, 비상제동 및 긴급 구원 취급을 위한 10개의 특수 스위치로 구성됩니다.

| 부품 ID | 스위치 명칭 | 형태 및 특징 |
| :--- | :--- | :--- |
| `SW_EMG_STOP` | **비상제동체결** | 3-Arrow 각인 적색 버섯형(E-Stop) 래치 버튼. 누르면 체결(BC 4.0 bar, [제동체결] 점등), 시계방향 회전 시 복귀 |
| `SW_FORCE_REL` | **강제완해** | 원형 적색 푸시버튼. 제동 고착 시 제동통 공기를 강제 배출하여 완해(BC 0.0 bar) |
| `SW_EMG_RELEASE` | **비상제동완해** | **투명 아크릴 안전커버(`SW_EMG_COVER`)** + 내부 적색 푸시버튼. 비상제동 불완해 시 강제 완해(BC 0.0 bar, [비상제동차단] 점등) |
| `SW_WIRELESS_MODE` | **무인모드 (ATO)** | **투명 아크릴 안전커버(`SW_WIRELESS_COVER`)** + 내부 녹색 푸시버튼. 4대 조건 충족 시 **3초 롱프레스**로 ATO 자동 주행 인가 |
| `SW_ATP_REV` | **ATP후진** | 투명 안전커버 + 내부 2단 로터리 스위치 (OFF / ON) |
| `SW_LOW_SPEED` | **저속도** | 2단 로터리 스위치 (정상 / 바이패스) |
| `SW_PARK_APPLY` | **주차제동체결** | 원형 녹색 푸시버튼 (1.0초 공압 배기음 연동) |
| `SW_PARK_REL` | **주차제동완해** | 원형 적색 푸시버튼 (1.0초 공압 배기음 연동) |
| `SW_ROOM_LIGHT` | **실내등** | 3단 로터리 스위치 (수동 / 자동 / 비상등) 왕복 회전 |
| `SW_RESCUE` | **구원운전** | 3단 로터리 스위치 (구원 / 정상 / 비상) 왕복 회전 |

## OP4 : 메인 계기 & 바이패스 (Main Gauges & Bypasses)

공기 압력 감시 및 보조 시스템 바이패스를 설정하는 패널입니다.

### 1. 공기 압력계 (MR & BC 듀얼 게이지)
* **MR (주공기탱크 압력, 적색 바늘)**: 기본 9.0 bar 유지
* **BC (제동통 공기압력, 흑색 바늘)**:
  * 평상시 / 완해 / 타행(N) / 역행(P1~P4): **`0.0 bar`**
  * 상용 제동: `B1`(2.3 bar), `B2`(2.7 bar), `B3`(3.0 bar), `B4`~`B7`(4.0 bar)
  * 비상 제동 (EB 노치 또는 비상제동체결 버튼 체결 시): **`4.0 bar`**

### 2. 보조 제어 스위치
* **와이퍼 4단 로터리 스위치**: `OFF` / 간헐(`INT`) / 저속(`LOW`) / 고속(`HIGH`)
* **장애물 감지 스위치**: 정상 / 바이패스
* **출입문 히터 스위치**: 수동 / 정지 / 자동 3단
* **공기질 개선 스위치**: 수동 / 정지 / 자동 3단

## OP5 : 보조 조작반 (Auxiliary Panel)

차상 신호(VOBC) 리셋 및 고전압 차단기/바이패스 스위치가 배치된 조작반입니다.

### 1. VOBC 리셋 스위치 (`SW_VOBC_RESET`)
* 노란색 원형 푸시버튼.
* **롱프레스 게이지 연동**:
  * **2~3초간 누름**: 해당차 단독 VOBC 리셋 진행.
  * **5~7초간 누름**: 전·후부 VOBC 전체 리셋 진행.
  * 7초 초과 시 타임아웃 경고 발생.

### 2. 하부 바이패스 및 차단기 스위치군
* **언커플링 스위치**: 연결기 분리 제어
* **고속도차단기 (HB) 스위치**: 주 회로 고속도 차단기 투입/차단
* **주공기 바이패스 (MR BP)**: 공압 누기 시 비상 공급 바이패스
* **PWM 차단 스위치**: 추진 인버터 PWM 제어 신호 차단
* **살사시험 스위치**: 모래 분사 장치 동작 시험
* **절연구간 스위치**: 사구간(Dead Section) 통과 준비
* **주차제동 바이패스 (PB BP)**: 주차제동 불완해 시 강제 완해 바이패스
