# 🚅 도시철도 열차 운전실 조작반 모바일 훈련 시뮬레이터 (Study)

> **실제 도시철도 전동차 운전실 조작반(OP1~OP5)과 전면 3D 주행 뷰를 실물 1:1 사진 기반으로 정밀 고증하고, 완전한 물리적 상호작용 및 전기·공압 인터록(Interlock) 논리를 구현한 고성능 웹 시뮬레이터입니다.**

## 📌 주요 특징 및 기술적 성과

> **2026-10 개편**: 메인(`/`)은 인천 2호선 실제 노선(201 검단오류 ↔ 227 운연)을 Three.js 3D로 구현한 새 버전이며, 실물 콘솔 배치(좌측 OP2~OP5 · 3D 전망 · DU · ADU · OP1)로 바뀌었습니다. 이전 버전은 **[`/old/`](https://l2l2l2l2.github.io/study/old/)**에 그대로 보관되어 있습니다.

1. **실물 전동차 운전실 조작반 고증 (OP1 ~ OP5) + DU · ADU · 차단기반**
   * **OP1**: 운전실 주 제어반 (주간제어기 T-bar 원핸들, 제어키, 전후진제어기 볼 노브, 축전지, COB 방송/통화 장치, 출입문 스위치)
   * **OP2**: 상부 표시등 조작반 (선두차지정 등 5대 인디케이터, 전면창 히터, 전조등 5단, 전기혼)
   * **OP3**: A필러 긴급 제동 조작반 (3-Arrow 비상제동체결 버섯형 래치, 아크릴 안전커버 비상제동완해, 무인모드 3초 롱프레스, 강제완해, ATP후진 등)
   * **OP4**: 메인 계기 및 운전모드 (MR/BC 공기 압력계, 운전모드 4단, 와이퍼 5단, 장애물 감지·출입문 바이패스, 공기질 개선)
   * **OP5**: 보조 조작반 (VOBC 리셋 2~3초 전환 / 5~7초 전체 리셋, 언커플링, 차단기/바이패스 스위치)
   * **DU / ADU**: 실물 화면 형태의 상태 칩(모드·HB·EB·PB·ADC/ADBS), 이벤트 메시지, VOBC 표시, 제한속도 호가 있는 속도계, Target Point, Door Enable
   * **차단기반 팝업**: 주 차단기(기존차) · 주 차단기(신조차) · 냉난방 스위치 3개 탭, 차단기 하나하나 ON/OFF

2. **철도 운전 취급 규정 기반의 인터록(Interlock) 논리**
   * **운전모드 OFF 인터록 (운전대 잠금)** 및 무인운전이 아닐 때 **HCR 비상제동(EB+HB)**
   * **무인운전모드(ATO) 3초 롱프레스 인가**: 운전모드 OFF, 키 OFF, 역전기 N, 마스콘 N 4대 조건. 곡선 설계속도를 반영해 최고 65 km/h로 역간 운행, 정위치 정차 후 출입문·PSD 8초 개방
   * **수동 운전 모드(FM, RM, ATPM)**: RM(제한수동)은 허용속도 15 km/h, 초과 시 비상제동
   * **선두차지정 점등 연동**: `운전모드(RM/FM/ATPM) + 키(ON) + 역전기(F/R)` 3중 조건
   * **공압 연동**: 마스콘 EB 또는 E-Stop 체결 시 BC 4.0 bar, 정차제동 2.0 bar, MR 8.0~10.0 bar 공기압축기 사이클

3. **인천 2호선 실제 노선 3D 전면 전망 (Three.js)**
   * 27개 역의 실제 역간 거리, 곡선, 구배, 고가/지하 구간, 건넘선 반영. 하선·상선 양방향 운행, 출발역 선택
   * 박스형·원형 **터널**과 조명, **강우**(지상 구간, 역 지붕 아래는 맑음)와 와이퍼, OP2 연동 **전조등**, 기존차/신조차 **반대편 열차**, 정지위치 표지와 25 m 위치 태그
   * 화질 자동 조절과 수동 선택(자동 / 100% / 75% / 55%)

4. **🎬 전시 모드 (무인 무한 왕복)**
   * 메뉴 하나로 201 ↔ 227을 무인운전으로 끝없이 왕복. 종착역에서 8초 뒤 자동 회차

5. **외부 오디오 파일 없는 Web Audio API 합성 사운드**
   * 라디오 PTT 잡음, COB 비프음, 인버터 모터음, 레일 조인트 충격음(Clack), 공압 배기음, 전기혼(F#4+A4), 공기압축기

6. **실물 콘솔 배치 화면**
   * 기본 배치와 와이드 모니터(21:9·32:9) 전용 배치
